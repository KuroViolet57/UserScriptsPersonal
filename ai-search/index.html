⚙️ Settings

Your keys and settings are stored only in this browser (localStorage). Nothing is sent anywhere except directly to the backend you configure.
Use an API/local-server endpoint (recommended for large uncensored models) or download a small HuggingFace model into your browser.
OpenAI-compatible. Examples: OpenRouter https://openrouter.ai/api/v1, Ollama http://localhost:11434/v1, KoboldCpp http://localhost:5001/v1, text-generation-webui http://localhost:5000/v1.
On OpenRouter pick a permissive/uncensored model. For a local server, use its model name (e.g. the one Ollama has pulled).
Must be a transformers.js-compatible model. Runs fully in your browser (downloaded & cached on first use). Small models only on phones. Note: most large "uncensored" models are not ONNX — for those use API/local-server mode.
Sets the assistant's behaviour. Editable. The default permits adult/NSFW output while forbidding illegal content.
For the "search engine" mode. Point to a SearXNG instance with JSON output + CORS enabled (self-hosting recommended; safesearch=0 is used). Leave blank to use the app as pure chat.
